## 2024-03-03 - Missing Security Foundations
**Vulnerability:** The repository lacked basic security foundations like `SECURITY.md` and automated dependency checking via `.github/dependabot.yml`.
**Learning:** Even empty or new repositories need these files to prevent accidental commits of sensitive data as development begins and to establish a process for reporting vulnerabilities and keeping dependencies secure.
**Prevention:** Include these files in the project template or initial commit.
