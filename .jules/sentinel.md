## 2024-03-17 - Missing SECURITY.md
**Vulnerability:** Repository lacked a security policy file, leaving users without clear instructions on how to report vulnerabilities.
**Learning:** Foundational repositories without application code still need a security policy, but it should direct users to GitHub Security Advisories rather than placeholder emails.
**Prevention:** Always create a SECURITY.md file pointing to GitHub Security Advisories for repositories without dedicated security contacts.
