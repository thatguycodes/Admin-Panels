# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by creating a GitHub Security Advisory in this repository.

1. Go to the **Security** tab of the repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Fill out the form with the details of the vulnerability.

We take all security issues seriously and will respond as quickly as possible. Please do not report security vulnerabilities through public GitHub issues.
