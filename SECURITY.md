# Security Policy

## Supported Versions

Currently, there are no specific versions of this project, but we aim to support security updates for all active branches.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately. If you find a security vulnerability, please contact the maintainers directly.

We will try to acknowledge your report within 48 hours, and will send a more detailed response within 72 hours indicating the next steps in handling your report.
