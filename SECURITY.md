# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. Instead, please report it by creating a GitHub Security Advisory in this repository.

To do this:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Fill in the details of the vulnerability and submit the report.

We will review the report and work with you to resolve the issue securely.
