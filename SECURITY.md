# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability for this repository, please create a GitHub Security Advisory in this repository.

To do so:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** on the left sidebar.
3. Click the **Report a vulnerability** button.
4. Fill out the details and submit the report.

Thank you for helping keep this project secure!
