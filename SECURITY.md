# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by creating a GitHub Security Advisory in the repository.

Do not report security vulnerabilities through public GitHub issues.

To create a security advisory:
1. Go to the "Security" tab in this repository.
2. Click on "Advisories".
3. Click "Report a vulnerability".
4. Fill out the form with details about the vulnerability.

We will review and respond to your advisory as soon as possible.
