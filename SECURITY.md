# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by creating a GitHub Security Advisory in this repository.

To do this:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Fill out the form with details about the vulnerability.

Please do not open a public issue for security vulnerabilities. We will review your report and respond as soon as possible.
