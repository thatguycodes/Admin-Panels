# Security Policy

## Supported Versions

Currently, only the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities by opening an issue on the repository, or by contacting the project maintainers directly if a private channel is available.

Do not disclose vulnerabilities publicly until a patch has been released.
