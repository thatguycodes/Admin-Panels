# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do not report it in the public issues.

Instead, please report it by creating a [GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) in this repository.

This ensures that the vulnerability can be disclosed and addressed responsibly.
